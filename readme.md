# 📚 DSA Learning System

A responsive DSA Learning System built using HTML, CSS, and JavaScript. This project allows users to register, log in, and explore different Data Structures and Algorithms with interactive visualizations.

## ✨ Features

- 👤 User Registration
- 🔐 User Login
- 🏠 Interactive Dashboard
- 📚 DSA Topics
- 🔄 Sorting Algorithms
- 🔍 Searching Algorithms
- 📋 Queue Operations
- 🔗 Linked List Operations
- 📦 Stack Operations
- 🌳 Binary Search Tree (BST) Operations
- 📱 Responsive Design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Project Flow

1. Register a new account.
2. Login to the system.
3. Open the Dashboard.
4. Select a Data Structure or Algorithm.
5. View definition, time complexity, uses, code, and visualization.
